Adopt Mica

# install from GitHub
pip install git+https://github.com/jordanaftali/micapybara

# then just run your tests as usual
pytest

# check on her any time
capy            capy feed       capy dance
capy stats      capy name Bia   pytest --no-capy

How she works

  • A pytest plugin reads every test run's results. She never changes your exit code or slows CI, and a problem in the plugin is skipped, never raised.
  • She is drawn in Python as a grid of colored pixels, then printed with truecolor half-blocks (▀), so each character shows two pixels.
  • Her saved state is a Pydantic model. Happiness stays between 0 and 100, names are checked, and a broken save file means a fresh capybara, not a crash.
  • Set NO_COLOR for plain blocks, MICAPYBARA_QUIET=1 to hide her, or --no-capy for one run.
